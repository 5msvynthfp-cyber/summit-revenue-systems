# Summit Revenue Systems website

Static one-page marketing site plus Privacy and Terms pages for Summit Revenue Systems (Louisville, Kentucky). Missed-lead recovery for local businesses.

This folder is a complete site. There is no build step and there are no trackers.

## Local preview

Open `index.html` in a browser, or from this folder run:

```
python3 -m http.server 8080
```

Then visit http://127.0.0.1:8080/

## Pages

- `index.html` home page (offer, how it works, pricing, FAQ, SMS opt-in disclosure, contact)
- `privacy.html` Privacy Policy (includes SMS consent, frequency, STOP/HELP, and no sharing of mobile numbers for third-party marketing)
- `terms.html` Terms of Service and SMS terms
- `404.html` GitHub Pages not-found page
- `demo/summit-missed-call-demo.mp4` demo walkthrough (labeled Demo: simulated conversation; the business is a fictional example), with `demo/poster.jpg` as the player poster
